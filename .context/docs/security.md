# Security

## Signature scheme

- Header: `X-Webhook-Signature: t=<unix seconds>,v1=<hex HMAC-SHA256>`.
- Signed content: `${t}.${rawBody}`. The timestamp is inside the MAC, so a receiver can reject old
  requests without trusting an unsigned header.
- `verify` (`src/domain/signature.ts`) rejects malformed headers, timestamps more than
  `toleranceSeconds` (300) away from now, and wrong digests; it compares digests with
  `timingSafeEqual` after checking their length.
- `v1` is a contract with every receiver. A new algorithm or signed content is a new `v2` part,
  sent next to `v1` during a migration, never a change to `v1`.

## Secrets

- The key is generated by Secrets Manager (48 characters, no punctuation) and **retained** when the
  stack is deleted, so receivers do not silently start failing verification after a redeploy.
- The function reads it with `GetSecretValue` once per container (`cachedSigningSecret`). It is
  never logged and never put in the environment.
- Rotation is manual today (see [tech-debt.md](tech-debt.md)).

## IAM and data

- Least privilege by CDK grants: consume the delivery queue, send to the dead-letter queue, read the
  one secret. Nothing else.
- Both queues use SQS-managed server-side encryption (SSE-SQS), stated in the stack.
- Payloads are customer data: never logged. Logs carry ids, event names, statuses and reasons.

## Outbound requests

- Only `https` URLs are accepted (`parseJob`); redirects are not followed (`redirect: 'manual'`), so
  a `3xx` cannot bounce the request to another host.
- Every request has a timeout (`REQUEST_TIMEOUT_MS`).

## Known gaps

- **SSRF**: anyone allowed to `SendMessage` can make the function POST to any `https` URL,
  including private addresses if the function ever runs in a VPC. Today it runs outside a VPC.
  Access to the queue is the control.
- No signing key rotation with overlap (`v1` with two keys).

## Static checks

CodeQL (`security-and-quality`) on every pull request and weekly; `eslint-plugin-sonarjs` security
rules (including `aws-sqs-unencrypted-queue`, which caught the implicit queue encryption);
`npm audit --omit=dev --audit-level=high` in CI; Dependabot for npm and GitHub Actions.
